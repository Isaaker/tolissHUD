# Security policy

## Supported versions

Security fixes are developed against the latest published version of this repository. Older versions may not receive fixes.

## Reporting a vulnerability

Please do **not** publish exploit details, credentials, private simulator files, or a weaponisable proof of concept in a public issue.

Use GitHub's **Report a vulnerability** / private security advisory feature for this repository. If private vulnerability reporting is unavailable, contact the repository maintainer through the contact method shown on the GitHub profile and ask for a private reporting channel.

Include the affected version / commit, X-Plane version, FlyWithLua version, ToLiss aircraft variant, reproduction steps, and the impact you observed. Redact account names, paths, tokens, and other personal data.

This is a community simulator add-on, not safety-critical or real-world aviation software. A security report is still welcome; please allow maintainers time to investigate before public disclosure.
